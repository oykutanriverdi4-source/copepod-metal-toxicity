# Data provenance and retained data files

This document describes the role of the data files retained in the reproducibility repository.

## 1. Original ECOTOX export

```text
data/raw/ecotox/ecotox_raw_export.xlsx
```

Role: original ECOTOX workbook used as the starting point for the scripted ECOTOX reconstruction.

Repository rule: retained unchanged as the raw ECOTOX input.

The workflow preserves native ECOTOX Reference, Test, and Result identifiers so that analytical records can be traced back to the source export.

## 2. Curated ECOTOX working master

```text
data/curated/ecotox/ecotox_working_master_harmonized.xlsx
```

Role: curated screening and harmonization decisions developed from the ECOTOX retrieval and original-source checks.

This file supports reconstruction of the retained ECOTOX analytical rows, harmonized concentrations, environmental metadata recovery, and documented exceptions.

## 3. Source-verified supplementary literature records

```text
data/curated/wos/wos_source_verified_records.xlsx
```

Role: curated quantitative records identified through the supplementary Web of Science route and verified against the original publications.

This is **not** the raw WoS bibliographic export. The raw WoS export is a local external input and is not redistributed.

The retained source-verified contribution is 57 quantitative LC50 Results from 17 publications.

## 4. Source-verification ledgers

```text
data/curated/source_verification/combined_source_adjudication_rows.csv
data/curated/source_verification/combined_source_verified_rows_used.csv
```

Role: preserve source-defined context, matching and adjudication information used by the within-Reference metal, stage, duration, environmental, covariance and sex-evidence workflows.

These ledgers are part of the analytical provenance and are used directly by several scripts.

## 5. Processed ECOTOX dataset

```text
data/processed/ecotox_harmonized.csv
```

Generated by:

```text
scripts/analysis/01_prepare_ecotox_data.R
```

Final reconstructed ECOTOX analytical dataset:

- 296 rows;
- 247 rows with harmonized positive molar LC50 values;
- 49 Cr(VI) rows retained as documented evidence but not used in analyses requiring a common molar LC50 because the concentration basis remained unresolved.

## 6. Combined processed dataset

```text
data/processed/combined_ecotox_wos_harmonized.csv
```

Generated by:

```text
scripts/analysis/02_integrate_wos_verified_records.R
```

Final combined dataset:

- 296 ECOTOX rows;
- 57 source-verified supplementary rows;
- 353 Results in total;
- 304 Results with a harmonized positive molar LC50;
- 49 Cr(VI) Results retained outside common-molar comparisons because of unresolved concentration basis.

## 7. Analysis-specific subsets

The main analytical subsets are generated by the scripted workflow rather than stored as manually edited master datasets.

Frozen final model domains are:

```text
Pooled 96-h Cu-Cd-Zn model:                  131 Results
Developmental-stage 96-h Cu-Cd model:         69 Results
Taxonomic-order 96-h Cu-Cd model:            101 Results
```

Support-audit RDS files record the exact rows passed to the stage and order models.

## 8. External database exports

Local-only inputs:

```text
data/external/wos/wos_raw_export.xls
data/external/envirotox/envirotox_raw_export.xlsx
```

These provider-supplied exports are intentionally not redistributed. Their exact search settings and audit workflows are documented in:

```text
documentation/wos_search.md
documentation/envirotox_search.md
```

The corresponding scripts remain available so that a user with access to the databases can reproduce those audit steps with their own exports.

## 9. Computational outputs versus reader-facing results

```text
outputs/
```

contains computational, QA, robustness, provenance and intermediate outputs.

```text
results/figures/
```

contains the thesis-facing PNG and PDF figures regenerated from the frozen analytical outputs.

The final figure script does not change the scientific analysis; it reconstructs the reader-facing figures from existing model and comparison outputs.
